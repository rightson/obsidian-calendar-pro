# Event Notes 0.3.0

Calendar Pro is now **Event Notes**. The plugin ID is `event-notes` and the GitHub repository is `rightson/obsidian-event-notes`. This release also adds a Gantt view for Project Notes.

## Moving from Calendar Pro

Event Notes installs as a separate plugin, but it brings your settings along:

1. Install Event Notes and enable it.
2. On its first start, with no settings of its own, it imports `data.json` and `recovery.json` from `<Vault>/.obsidian/plugins/calendar-pro/`, or from `calendar-note/` if that folder does not exist. It imports only when that folder's `manifest.json` lists the author `rightson`, so another author's plugin with the same ID is ignored. A notice tells you when settings were imported.
3. Disable and remove **Calendar Pro** so the two plugins don't both edit the same notes.
4. If you use BRAT, add `rightson/obsidian-event-notes` and remove `rightson/obsidian-calendar-pro`.

Your Event, Daily, and Weekly Notes are unchanged. Calendar tabs left open from Calendar Pro need to be opened again. See [moving from Calendar Pro or Calendar-Note](https://github.com/rightson/obsidian-event-notes/blob/main/docs/manuals/INSTALLATION.md#moving-from-calendar-pro-or-calendar-note).

## Projects and Gantt

- Open any outline as a WBS table or a Gantt chart: from the chart button in the note's title bar, the **Open current note as Gantt** command, or **Open as Gantt** in the file menu.
- Dates, progress, milestones, and assignees go in brackets at the end of a line, such as `(30%, 11/1-11/6, @小王)` or `(◆ 11/30)`. Full-width brackets work too, and brackets with anything else stay as your own remarks.
- Edit cells in **Table** or drag unscheduled rows onto the timeline in **Chart**, and the plugin writes the brackets for you, after showing a preview the first time.
- Linked assignees such as `@[[小王]]` or `[[@小王]]` link to the person notes in your Vault.
- Compact table, inline renaming, folding levels, and zoom. Folding, zoom, and column width are remembered per Gantt tab, never in the note.
- Dated tasks appear in the calendar's all-day row.

See the [Gantt quick start](https://github.com/rightson/obsidian-event-notes/blob/main/docs/manuals/GANTT.md).

## Calendar

- A more compact event details dialog.
- The Events sidebar keeps the current time centred, previews tomorrow late at night and the previous day just after midnight, and keeps the time of day when you change dates.

## Install

**Download the [Event Notes 0.3.0 ZIP](https://github.com/rightson/obsidian-event-notes/releases/download/0.3.0/event-notes.zip)**, extract it, and copy the `event-notes` folder into `<Vault>/.obsidian/plugins/`, or install through BRAT. See the [installation guide](https://github.com/rightson/obsidian-event-notes/blob/main/docs/manuals/INSTALLATION.md).

## Compatibility and verification

Requires Obsidian 1.14.5 or later on desktop. Settings import has automated tests only; it has not had native Obsidian QA. The Gantt view has automated coverage; its native checks, listed in the [native test-Vault checklist](https://github.com/rightson/obsidian-event-notes/blob/main/docs/manuals/DEVELOPMENT.md#native-obsidian-test-vault-checklist), have not been run yet.
