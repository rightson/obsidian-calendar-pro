# Event Notes 0.3.4

A redesigned calendar toolbar, and calendar subscriptions you can add without leaving the calendar.

- **A cleaner toolbar.** Navigation sits on the left as one **‹ Today ›** control, followed by the period and its week number. Display options (**Workdays** and the view picker) and actions sit on the right: icons for refresh and change history, where a badge counts changes waiting for review, then an accent **+ New event**, and **⋯**. All controls share one height. In narrow panes the right group moves to its own row, and **New event** shrinks to its **+** icon.
- **Add iCal subscriptions from the calendar.** **⋯ → Add calendar subscription…** asks for the feed URL (HTTPS or `webcal://`) and, optionally, a name, color, and calendar type. The same menu turns each subscription on or off, and **Event Notes settings…** opens the plugin's settings. The **Add calendar subscription** command opens the same dialog.
- **No repeated dates with both panels open.** When the sidebar and the main calendar are both shown, the sidebar keeps only **‹ ›** to page its months, and the main toolbar leaves out the week chip. The sidebar shades the days the main calendar shows, and its week numbers open Weekly Notes. Hiding either panel brings the hidden controls back.
- **Aligned panes.** The calendar sidebar, main toolbar, month calendar sidebar, and Events sidebar start their first row at the same height, and the calendar sidebar now reaches the edge of its pane. The month calendar sidebar uses the same **‹ Today ›** control after its title.

## Install

**Download the [Event Notes 0.3.4 ZIP](https://github.com/rightson/obsidian-event-notes/releases/download/0.3.4/event-notes.zip)**, extract it, and copy the `event-notes` folder into `<Vault>/.obsidian/plugins/`, or install through BRAT. Moving from Calendar Pro is covered in the [installation guide](https://github.com/rightson/obsidian-event-notes/blob/main/docs/manuals/INSTALLATION.md#moving-from-calendar-pro-or-calendar-note).

## Compatibility and verification

Requires Obsidian 1.14.5 or later on desktop. `npm run typecheck`, `npm test`, and `npm run package` pass. Toolbar and heading alignment was checked in a browser mock built from the plugin's stylesheet. The subscription dialog, the **⋯** menu, and the shaded days in the sidebar have automated coverage only and have not had native QA in Obsidian.
