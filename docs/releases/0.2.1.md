# Calendar Pro 0.2.1

The Events sidebar and the month calendar sidebar open with their content again.

## Fixes

- In 0.2.0 both sidebars opened blank, and Obsidian's console showed `Failed to open view TypeError: Cannot read properties of undefined (reading 'setText')`. They now render as described in the [0.2.0 release notes](0.2.0.md#events-sidebar).

## Install

**Download the [Calendar Pro 0.2.1 ZIP](https://github.com/rightson/obsidian-calendar-pro/releases/download/0.2.1/calendar-pro.zip)**, extract it, and replace the `calendar-pro` folder in `<Vault>/.obsidian/plugins/`, or update through BRAT. See the [installation guide](https://github.com/rightson/obsidian-calendar-pro/blob/main/docs/manuals/INSTALLATION.md) for safe updates.

## Compatibility and verification

Requires Obsidian 1.14.5 or later on desktop. An automated test guards against the cause; the fix has not had native Obsidian QA. The [0.1.0 verified scope](https://github.com/rightson/obsidian-calendar-pro/blob/main/docs/releases/0.1.0.md#compatibility-and-verification) still describes what was checked in Obsidian.
