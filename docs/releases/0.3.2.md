# Event Notes 0.3.2

A maintenance release that follows the official Obsidian plugin guidelines more closely.

- **Deleted Event Notes go to the trash you chose in Obsidian.** When the calendar deletes an Event Note, it now uses Obsidian's file manager, which respects **Settings → Files and links → Deleted files** (system trash, the Vault's `.trash` folder, or permanent deletion). Earlier versions always deleted the file permanently.
- Calendar views, the month calendar, and the Gantt view use the active window's document and timers, so they work in pop-out windows.
- Buttons and labels are built with Obsidian's element helpers, and opening a note checks that the Vault entry is a file instead of assuming it.
- `moment` is listed as a direct dependency, since the date code imports its locales.

## Install

**Download the [Event Notes 0.3.2 ZIP](https://github.com/rightson/obsidian-event-notes/releases/download/0.3.2/event-notes.zip)**, extract it, and copy the `event-notes` folder into `<Vault>/.obsidian/plugins/`, or install through BRAT. Moving from Calendar Pro is covered in the [installation guide](https://github.com/rightson/obsidian-event-notes/blob/main/docs/manuals/INSTALLATION.md#moving-from-calendar-pro-or-calendar-note).

## Compatibility and verification

Requires Obsidian 1.14.5 or later on desktop. `npm run typecheck`, all 271 tests, and the official `eslint-plugin-obsidianmd` 0.5.1 recommended rules pass with 0 errors. Three warnings remain about moving the settings tab to Obsidian 1.13's declarative settings; the current settings tab still works. These changes have not had native Obsidian QA.
