# Event Notes 0.3.3

A maintenance release that clears the remaining style warnings and moves settings into Obsidian's search.

- **Plugin settings appear in Obsidian settings search.** Searching for a setting name in **Settings** now finds the matching Event Notes option.
- Holidays without a color keep a dotted mark under the date in the month calendar and the sidebar month view. The mark is now a dotted border and takes no extra space.
- Layout gaps use the `gap` shorthand, and the stylesheet no longer uses `!important`. The Events sidebar and Gantt view keep their full-bleed layout, and date and week-number links in the calendar stay without underlines on hover.

## Install

**Download the [Event Notes 0.3.3 ZIP](https://github.com/rightson/obsidian-event-notes/releases/download/0.3.3/event-notes.zip)**, extract it, and copy the `event-notes` folder into `<Vault>/.obsidian/plugins/`, or install through BRAT. Moving from Calendar Pro is covered in the [installation guide](https://github.com/rightson/obsidian-event-notes/blob/main/docs/manuals/INSTALLATION.md#moving-from-calendar-pro-or-calendar-note).

## Compatibility and verification

Requires Obsidian 1.14.5 or later on desktop. `npm run typecheck`, `npm test`, and `npm run build` pass. The settings tab, settings search, Calendar, Events sidebar, and Gantt view were checked in Obsidian 1.15.0 on macOS.
