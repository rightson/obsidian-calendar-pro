# Event Notes 0.3.1

A maintenance release for the Obsidian Community directory review.

- Removes six unnecessary TypeScript type assertions that the official Obsidian ESLint rules report as errors. Behavior is unchanged.
- `versions.json` now lists only Event Notes releases. Earlier releases were published as Calendar Pro or Calendar-Note with other plugin IDs, so Obsidian should never offer them as a compatible version of Event Notes.

## Install

**Download the [Event Notes 0.3.1 ZIP](https://github.com/rightson/obsidian-event-notes/releases/download/0.3.1/event-notes.zip)**, extract it, and copy the `event-notes` folder into `<Vault>/.obsidian/plugins/`, or install through BRAT. Moving from Calendar Pro is covered in the [0.3.0 notes](0.3.0.md) and the [installation guide](https://github.com/rightson/obsidian-event-notes/blob/main/docs/manuals/INSTALLATION.md#moving-from-calendar-pro-or-calendar-note).

## Compatibility and verification

Requires Obsidian 1.14.5 or later on desktop. `npm run typecheck`, all 271 tests, and the official `eslint-plugin-obsidianmd` 0.5.1 recommended rules (0 errors) pass.
